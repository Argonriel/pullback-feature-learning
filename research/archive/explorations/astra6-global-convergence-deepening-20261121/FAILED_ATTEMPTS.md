# Failed and rejected routes retained

Date: 2026-11-21, America/Los_Angeles.

1. **Ordinary reverse-Bregman Lyapunov function for every SPD weight: rejected mathematically.** The initial attractive route was to compare the entropy Hessian with the inverse-Lyapunov metric and infer descent. Although the spectral comparison is positive, its product with an arbitrary positive definite observation Hessian need not have a positive quadratic form. Exact classified 2-by-2 counterexamples and finite-difference controls are retained in the independent reports. The successful quantitative claim is restricted to geometry-adapted weights.
2. **Strict feasibility as a requirement for all convergence: narrowed.** Inspection showed that the existing proof establishes global PSD minimization before invoking feasibility. The stronger correct result is a closed-cone Bregman selection theorem. Strict feasibility is necessary and sufficient for an SPD endpoint, and boundary examples preclude an unconditional exponential rate.
3. **Weight-independent endpoint for inconsistent data: rejected.** The exact diagonal problem with target (-1,1) has optimal points (0,1) and (0,1/2) for two SPD observation weights. Both satisfy convex PSD KKT conditions. Weight independence remains valid for a common feasible interpolation set, or more generally a fixed common optimal fiber.
4. **Bare Python launcher: environment failure.** The command `python` resolved to an inaccessible WindowsApps alias and did not execute. The bundled runtime located by the desktop dependency tool was used instead.
5. **SciPy import: environment failure.** The bundled runtime raised `ModuleNotFoundError: No module named 'scipy'`. No package installation was attempted. The new boundary validation uses NumPy and explicit RK4 only.
6. **Primary-source direct downloads: access failure.** The literature agent records DNS/access failures and preserved extracted web-tool records. Their hashes identify those saved extracts, not complete publisher PDF bytes. The audit labels partially accessible extra sources as screens, not verified theorem comparisons.
7. **A guessed report filename: benign read failure.** A root read of `independent_spectral/QUANTITATIVE_BOUND.md` failed because the agent's actual filename differed. No content was lost or modified. Subsequent reads use the actual inventory.

No mathematical failure was replaced by a larger training run. No retired gate, scalar-depth, poisoning, topology, or reserved-sample route was reopened.
