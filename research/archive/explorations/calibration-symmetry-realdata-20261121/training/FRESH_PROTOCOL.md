# Locked confirmation, exported models, and selector comparisons

The four-seed pilot determines only the PB and GD hyperparameters. Each fresh model uses its own independent validation set to choose one of the four frozen checkpoints. `model.py`, the original task/model source, the pilot specification, and all pilot outcomes remain unchanged. The complete confirmation implementation is committed before any 2101–2108 fresh stream is generated.

The exported state families are `legacy_pb`, `selected_pb`, and `selected_gd`, all sharing the same 256 training inputs and initialization within each of 16 replications. Each has raw and temperature variants: `legacy_raw`, `legacy_temp`, `pb_raw`, `pb_temp`, `gd_raw`, and `gd_temp`. No family is dropped if it performs poorly. Failed training or calibration is retained as a failed record and stops the affected pipeline; it is never silently replaced.

`states/{pair}.npz` contains x,y,initial and the three chosen states, plus all selected-model checkpoints. `temperatures/{pair}.json` contains each family's positive inverse temperature and its sampled-label fit diagnostics. `splits/{pair}.npz` contains independent validation and temperature inputs/labels. The model commit hashes these artifacts before selector calibration; the policy commit hashes every selector before performance evaluation.

The portable adapter is `adapters.load_variant(pair,variant)` returning `(adapter,theta,metadata)`. `adapter.predict(theta,x)` returns beta times the base logit; `adapter.partner(x)` flips only the first coordinate pair. `difference_bound(theta)` is beta times the original certified half-turn logit-difference bound. The generic `network_constants` residual constant includes the compact-support correction `1.4*abs(beta-1)` because the scaled logit is no longer x1 plus only scaled residuals. Robustness code should prefer `difference_bound` to avoid unnecessary looseness. No calibrated network weights are fabricated.

Both selectors are inherited unchanged from the preceding method: 16×16×256 midpoint orbit grid and a 16×16×16 folded histogram with its frozen empty-cell mean fallback. Each has 65,536 standalone model-forward examples. Raw and temperature variants share identical base-network calibration logits, and temperature-scaled Jensen fields are recomputed algebraically. This saves actual forward work; the raw and temperature variants are not charged twice for the same cached base logits. Actual shared calls, standalone equivalent calls, and scalar postprocessing are distinguished. Each base family costs 131,072 forwards for both selector calibration designs, or 393,216 actual forwards per replication across all three families. There is no selector search on fresh outcomes.

Performance evaluates raw, full half-turn, folded, and interpolated prediction for each of the six variants on the same 65,536 iid inputs and tie keys per replication. Deployment is physically replayed with exactly [256] calls for raw, [256,256] for full, and [256,64] for either quota policy. Replaying six variants independently records the actual execution cost of this experiment; potential caching of raw and temperature performance predictions is not claimed as executed. The 1.25-call quota budget excludes training, validation, and offline calibration, which are reported separately.

The four primary paired log-loss comparisons are (1) selected PB plus temperature raw risk minus legacy PB raw risk, (2) selected PB raw risk minus legacy PB raw risk, (3) legacy PB plus temperature raw risk minus legacy PB raw risk, and (4) selected PB plus temperature interpolated risk minus its raw risk. For each, report all 16 paired differences, wins, mean difference, and a 20,000-draw seed-cluster bootstrap interval at two-sided alpha=0.05/4 using seed 2109001. This is descriptive finite-model bootstrap uncertainty, not the distribution-free certificate developed separately. Class-error, selected-PB temperature-only, strong-histogram, and GD contrasts are retained as descriptive secondary comparisons, without relabeling a winner as primary. The known posterior is used only in this performance stage and descriptive evaluation; sampled-label risks use independent label stream 2108000+pair.

Fixed reliability summaries use ten equal-width predicted-probability bins. Expected Brier loss, squared posterior error, mean top-label confidence, and expected accuracy are saved for every variant/policy/seed. No new recalibrator, threshold, or temperature is fitted to performance outputs. A positive temperature leaves unaugmented classification signs exactly unchanged; this is explicitly checked.

One limitation is built in: the new procedures use more labeled data than legacy raw (2,048 validation labels and/or 2,048 temperature labels in addition to 256 training labels). Their comparison answers whether those held-out fitting resources improve the result, not whether more accuracy was obtained at equal total label budget. PB and GD match maximum update and search budgets, but not wall-clock computation or optimizer geometry.
