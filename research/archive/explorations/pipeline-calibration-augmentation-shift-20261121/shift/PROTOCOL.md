# Prospective controlled input-law mismatch protocol

Frozen before all 217-family verification and performance draws. No new training, no model or policy selection, no new architecture. Use the first eight legacy_raw model indices from the preceding study, with their unchanged interpolation and strong folded-histogram tables. The original manifest, model-array provenance, and copied table hashes are retained in HISTORICAL_INPUTS.json. Historical selector fitting used 65,536 model forwards per table and labels were not used by the selectors. Historical model training did use labels. There is zero new model or selector fitting cost in this branch.

The two selectors are pointwise half-turn-even, selecting exactly 64 of each 256 inputs. Deploying either uses 256 original and 64 transformed model evaluations. Verification may evaluate both views only on the union of their selected inputs, costing 2 times the union size, between 128 and 256 forwards per batch. Inputs and coordinate-based selection are still counted separately.

Input laws have orientation density (1+a cos(phi))/(2pi), a in {0,.01,.1,.6}, with known TV 2a/pi. These values include a small departure and are fixed before new draws. Certificate inputs for pair i and law index j=0..3 use seed 2171000+100j+i; tie keys use 2172000+100j+i. Draw 2048 batches, retain the fixed nested 512-batch look, and make 2048 the primary result. Eight models x four laws x two policies x two moments x two concentration methods x two looks = 512 simultaneous events, delta=.05/512. Clip c=min(.5,max(1e-6,q95(historical grid Jensen))) is shared between policies per model and committed before verification. D=min(1.4+C,1.4L), from the fixed unscaled model, is not fitted to observed extrema.

Independent performance inputs use seed 2173000+100j+i and ties 2174000+100j+i, 65,536 inputs per model/law. Known posterior evaluation consumes no sampled labels. Defect grid epsilon={0,.025,.05,.1,.2,.4,.8,1}; worlds q=cos(phi) and q=sign((h-hT)/2). Set p=p0+min(epsilon/2,p0,1-p0)*q and pT with the opposite sign. Each has posterior TV at most epsilon. The adversarial world is model-dependent, and therefore is not one common population shared by all eight models. Raw, full averaging, interpolation, folded and confidence allocation are retained. Confidence is an empirical comparator outside the structural certificate. Expected NLL, expected classification error, direct IID gain, and known-density conditional orbit-corrected gain are stored. The latter is not the ordinary unweighted paired-law risk, and is not a new certificate. Direct and corrected quantities are both reported.

Save model/law-specific raw moments, logits, posteriors, packed masks, seeds, hashes and actual call ledgers. Replay one full deployment batch for each limited policy per model/law, charging those extra calls. Preserve any failed numerical checks and negative gains; no budget increase or range/clip/shift retuning after outputs.

The multiclass component is a proof and numerical algebra audit, not a trained multiclass model confirmation: K=2,3,10 random logit/posterior pairs at scales .1,1,5,20, with arbitrary independent common logit offsets. Check the exact pairing identity, posterior-TV range inequality, loss-range inequality, common-offset invariance and Jensen upper bound. Audit seed 2179000; sampler diagnostics 2178000+j, each 65,536 inputs, counted as coordinate-only work. A deterministic dense angular sum checks the TV formula. Binary empirical identities are checked on every performance record. No natural-image posterior defect or input TV is inferred from unlabeled data.

Primary certificate reporting uses all individual lines and per-law counts with positive bounds at each epsilon, plus maximum certifiable eta at epsilon zero for context. Descriptive means/ranges across the eight fixed historical models are not new-model confidence intervals. Empirical Monte Carlo standard errors use independent batches. No statistical significance test is used to choose outcomes for display.

Run stages: assets.py once to vendor prior inputs; run.py freeze; obtain internal ROOT_APPROVAL.json binding the freeze; run.py prepare; run.py checks; run.py certificate; run.py stress; analyze.py. The internal release is part of scientific separation, not a request for additional user permission. All runtime paths after assets.py are relative and the archived branch is standalone.
