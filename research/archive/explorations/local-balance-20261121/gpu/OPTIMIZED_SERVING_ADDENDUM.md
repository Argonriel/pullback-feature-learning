# Pre-test implementation control

The original frozen benchmark remains unchanged. Code review found that Boolean tensor gathers implicitly require dynamic index discovery. Because the quota is exactly 64, an additional implementation instead carries 64 integer indices through gather/scatter. This removes unnecessary dynamic-index overhead while preserving the trained models, calibration, policy definitions, precision and test streams.

The optimized confidence path uses the monotone IEEE bit ordering of finite absolute FP32 logits. Its integer priority combines the inverse absolute-logit bit rank with independent tie rank, then uses top-k on unique integer keys. This exactly preserves the original confidence/tie ordering, including duplicates and signed zero, without a host-side tie check or a conditional no-ties fast path. Nonfinite model outputs remain a visible failure. Synthetic checks cover signed zero, duplicate values, subnormals and extreme finite values.

The folded path uses exact integer ranks of the FP32 cell scores and independent tie ranks, then top-k on the resulting unique integer keys. It preserves descending score and ascending tie order exactly. Fused full inference still uses 512 examples in one call; fused folded inference uses 320 examples in one call. The original and optimized implementations are measured together in randomized blocks, including the original Boolean-index path for transparency. No artificial operations are added to either baseline.

All nine trained models and both policy tables per model were committed before this addendum. Neither GPU test risks nor timing outcomes had been inspected. The addendum is frozen before test scoring, equivalence auditing or timing. All 16,384 test inputs per model enter both GPU and CPU equivalence audits. A mismatch fails visibly and is retained, with no silent replacement of the scientific selector. Timing uses the first 4,096 observations of that audited 16,384-observation test draw; the smaller count is not passed afresh to the sampler because that would produce a different draw.

Timing is deferred until the root confirms the main CPU work is complete. Report optimized and original results separately and use the fastest measured equivalent full implementation within the same device/transfer condition for conservative amortization comparisons. The original calibration wall time is shared by the two implementation variants. Timing repeats remain repeated measurements, not independent trained models.
