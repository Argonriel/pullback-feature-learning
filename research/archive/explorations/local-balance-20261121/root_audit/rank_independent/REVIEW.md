# Independent review of global exact-quota ranking

For every nonzero integer frequency and every phase, the fractional angular score is uniform conditional on radius. An action mixture depending only on radius preserves that law. Conditional on a frozen calibration, scores of independent future inputs are iid and continuous for positive width. Therefore selecting the top 64 of 256 gives the actual inclusion function Q(F(s)), with Q the Beta(192,64) CDF. Its derivative maximum and the implemented binomial polynomial agree.

The FFT formula is a cross-correlation with the correct sign and normalization. The original implementation sampled some even-frequency sawtooth discontinuities exactly on its angular grid. The independent modular-grid checks passed, but evaluating the same grid through ordinary floating coordinates produced differences as large as 0.00127767 in the objective and 0.00141092 in the moment. These are preserved in `review_v1.json` and `fft_v1.json`, with the pre-phase source snapshot. The original auditor driver first needed a guard for an empty opposite-sign pair set; that audit-code exception did not change the selection method or any scientific result.

After the quarter-grid phase correction, direct modular and floating-coordinate sums agree with FFT to below 8.4e-17. The upper-hull optimizer agrees with independently enumerated feasible one- and two-action mixtures to below 1.4e-17. All tested batches select exactly 64, and the even policy's mask is unchanged when every third input is negated while action and tie keys are fixed. Corrected results are in `review_v2.json` and `fft_v2.json`.

The DKW/BV/radial-error theorem also checks out. The empirical CDF error for the fixed radial score profile contracts under uniform convolution, uniformly over positive widths, including a width chosen from the same calibration sample. Fitting action mixtures does not change the score distribution. The angular variation bound includes both monotone sections and all sawtooth jumps. The radial interpolation bound correctly includes changes in network logits and in the radial score location, weighted by the odd-action masses. Even actions have exactly zero conditional moment by half-turn symmetry, independently of CDF estimation.

A minor negative-radius API inconsistency was flagged before freezing: applying a negative-radius cap after an outside-domain zero mask could return a negative bound for an impossible physical radius. Actual radii are nonnegative norms. The investigator was asked to apply the outside-domain mask after the final cap. This has no effect on any sampled input or primary result.

The learned odd-frequency policy remains only approximately balanced. Anchor LP residuals alone do not prove balance between radii or under the population score law. The new bound explicitly addresses these errors, although it can be numerically loose. Numerical known-input-law quadrature is an evaluation diagnostic, not an analytic certificate. A larger allocation family, improved empirical risk, useful high-probability error bound, and exact conditional identification are separate conclusions.

The independent numerical audit uses prior model `121_1`, tau=1, six radial anchors, four frequencies, and six phases per frequency. It verifies formula and implementation consistency; it is not a fresh-cohort performance experiment. Root separately audits the frozen new-cohort deployment and outcomes.
