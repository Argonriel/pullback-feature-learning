## Harmonic-amplitude task

For a balanced class labelY, drawU|Y=0 fromBeta(2,5) andU|Y=1 fromBeta(5,2), setR=0.4+U and draw a uniform phasePhi. ObserveX=(cosPhi,sinPhi,R cos2Phi,R sin2Phi). The action is R_theta direct-sum R_2theta; its half-turn flips only the first coordinate pair. The posterior is U^3/[U^3+(1-U)^3]. The marginal CDF ofU is7.5U^2−20U^3+22.5U^4−9U^5. Bayes classification error is7/64.

This is controlled synthetic transfer across input dimension, action representation and noise law. The quotient remains a scalar and is monotone with total input norm on the support. It is not a general multidimensional-quotient or real-data validation.

The generic two-block residual network has width8 and144 parameters in4D, compared with80 parameters in2D. Primary comparisons are selectors applied to exactly the same trained state. No equal-training-cost or optimizer-superiority claim is planned.

## Certificate assumptions

The strongest proposed certificate uses the known synthetic input marginal to enclose the true rank-score CDF deterministically. That distribution is evaluator-only: it must not change deployment scores, actions or masks. Empirical-CDF uncertainty is evaluated separately and never silently removed. Real-arithmetic mathematical guarantees and float64 numerical implementations are explicitly distinguished; no formal directed-rounding proof is claimed.

The root finite-sample verifier uses an independent coordinate-only sample and antithetic network evaluations. For d=(h(X)−h(TX))/2, A=softplus(h(X))−softplus((h(X)+h(TX))/2), and actual rank inclusion probabilityq, defineW=[q(X)(A−d/2)+q(TX)(A(TX)+d/2)]/2. Every invariant posteriorp satisfies gain>=E[W]−E[|E(qd|R)|]/2. Valid lower enclosures ofW and upper boundsB(R) therefore giveZ=W_lower−B(R)/2. A one-sided empirical-Bernstein lower confidence bound onE[Z] completes the certificate.

With|d|<=D andq in[0,1], W lies in[−D/4,D/2]. Conservative interval evaluation may use the wider range[−D/2,D/2] unless its tighter range is proved. The statistical protocol and implementation are frozen before fresh observations. Confidence allocations cover all named fresh models and all uncertainty events actually used.
