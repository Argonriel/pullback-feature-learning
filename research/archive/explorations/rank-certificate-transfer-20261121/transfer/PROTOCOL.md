# Transfer task and method freeze

This directory defines the four-dimensional two-harmonic task, residual model, old-task adaptation of the frozen rank family, and separate four-seed pilot. The confirmation cohort must not be generated until `FREEZE.json` exists and the parent authorizes validation.

The pilot uses training seeds 1031001..1031004 and initialization seeds 1032001..1032004. Each model sees the same 256 training inputs across optimizer recipes, with exactly 128 observations per class. Four recipes are preserved: GD rates .1 and .3, and PB rates 8 and 16, each 500 updates with PB damping .1. Pilot evaluation seeds 1033001..1033004 provide 16,384 iid inputs each. The per-optimizer rate minimizes the mean conditional logistic risk on these pilot inputs; this training choice explicitly uses posterior supervision. It selected PB8 and GD.3. No new selector parameter was searched: tau remains 1 from the prior study.

The frozen primary confirmation uses 16 independent PB models, training seeds 1041001..1041016 and initialization seeds 1042001..1042016, 500 updates at rate8 and damping.1. GD.3/500 is a secondary descriptive training context. Fresh transfer calibration seeds use 1043000+seed for rank fitting and 1044000+seed for the strong folded baseline; test inputs use 1045000+seed, ties1046000+seed, action keys1047000+seed, and independent sampled labels1048000+seed. Certificate probes1051000+seed and crosschecks1052000+seed are separate. Every method must use the same independent test batches within a model.

Primary selection methods are the unchanged rank-balanced, rank-even, and unconstrained rank controls. Independent validation also retains confidence, invariant folded, uniform random, radius-based controls where applicable, raw inference, and the full two-view reference. Full two-view inference costs two calls/input and is not a same-budget competitor or a universal ceiling. All limited-view policies must select exactly64/256 and use the correct partner diag(-1,-1,+1,+1). The folded baseline must fit the transfer quotient r=norm(last two coordinates) and a canonical first-harmonic angle modulo pi; using the old full-input norm or the Euclidean antipode would be incorrect.

The rank calibrator spends exactly66,048 model example forwards and131,072 additional coordinate-only radii per model. The strong folded baseline receives the same forward budget through an iid input/partner calibration design. Any lower-budget auxiliary angle methods must retain their declared budget. Selection must not evaluate all candidate partner logits before choosing a mask. Recorded call counts, calibrated policy hashes, all failed attempts, and all losing methods are retained.

Population conditional risk is primary; independent sampled-label risk and the prespecified invariant posterior worlds are secondary. Inference clusters by16 model seeds, not by individual test batches. The task's exact-even score has a structural balance guarantee. Learned balance, posterior ambiguity, certified bounds, and original-task risk comparisons are reported separately. No task-specific success claim is based on the underfit GD context, and no result is labeled real-world or multidimensional-quotient validation.

## Source and API

`task.py` supplies `sample_train(seed,n)`, `sample_inputs(seed,n)`, `sample_test(seed,n)`, `initialize(seed)`, `train(theta,x,y,**TRAIN_CONFIG[method])`, `predict(theta,x)`, `partner(x)`, `transform(x,angle)`, `quotient(x)`, `angle(x)`, the radial density/CDF/moment primitives, and the unpacked residual blocks. `sample_train` returns x,y; `sample_test` returns x,y,p; `train` returns fitted parameters and training metadata. The model has144 parameters.

`rank_policy.py` supplies the same frozen-policy interface as before: `calibrate(theta,seed,tau=None)` returns plain arrays/scalars, and `select(x,first,table,name,ties,action_keys)` returns a flat Boolean mask. The default tau is1. All policies use the task's half-turn partner. `population_cdf` and `marginal` are evaluator-only. Load saved arrays into memory before timing. `ADAPTER_PROVENANCE.json` records the unchanged reference source and the geometry-specific adaptations.

`pilot.py` and `checks.py` reproduce their outputs into fresh directories and refuse to overwrite existing results. Preserve the original directories before rerunning. `task_pilot_v1.py` preserves the exact model source used by the initial training pilot; subsequent additions only expose the fixed training configuration and analytical input-law helpers. Requirements are NumPy and threadpoolctl; reporting may additionally use matplotlib. Everything needed for this task is included locally, with no dependency on external archives.
