# Repository guidelines

- Keep all repository content in English.
- Keep implementation, reusable configurations, tests, and concise usage documentation in Git.
- Store research notes, proposals, literature reviews, analysis, result tables, figures, run records, and report drafts in the user's separate local research archive.
- The ignored root paths `docs/`, `reports/`, and `runs/` may be directory links into that archive. Inspect their targets before moving or deleting them. Never force-add these paths to Git.
- Preserve existing research outputs. Use a fresh output directory for each new run.
- Preserve frozen configurations and historical protocol checks unless an explicitly documented new experiment requires a change.
- Do not rewrite published Git history as part of ordinary repository cleanup.
